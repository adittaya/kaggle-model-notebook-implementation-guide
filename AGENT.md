## Notes for future agents

- Do NOT hard-code tokens in the notebook. Use Kaggle Secrets (`HF_TOKEN`, `KAGGLE_KEY`).
- All caches/models under `/tmp`, session-only.
- Dual-T4 designs must use host-staged exchange, not raw P2P, on T4 PCIe (`exchange="host"`, `chunks=8`).
- Turbo/TeaCache/Spectrum/FBC stay OFF for the quality-first build.
- Kaggle GPU RAM is **31.3 GB** → no pinned weight caches (18 GiB DiT cache would OOM).
- Comfy template JSON = *saved* workflow (nodes/links/subgraphs). `/prompt` = *API* prompt
  (`{id: {class_type, inputs}}`, link ids as strings). Always convert; always verify against
  `GET /object_info`.
- When a Kaggle run fails, download the log **and print the HTTP error body** — every fix in the
  v5→v11 chain came from the body, not the traceback.
- After any change: rebuild (`python3 build_full.py`), `ast`-validate every cell, `kaggle kernels push`,
  `git add -A && git commit && git push`, **and update all six MD files**.
